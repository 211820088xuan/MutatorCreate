| 指标 | 实测 |

### A1-3：`run_reps.sh` 的输出目录分配

```bash
21:    OUT=$ROOT/rep$(printf %02d "$r")/$arm
22:    mkdir -p "$OUT/corpus" "$OUT/crash"
28:        "$BIN" -max_total_time="$DUR" -fork=1 -detect_leaks=0 -seed=$((SEED_BASE + r)) \
```

- **输出目录是分开的**（`rep%02d/$arm`），不存在两个 run 写同一目录的可能。
- **但 `-seed` 是根因**：修之前是硬编码 `-seed=1`（本次实测时该行已是修好的版本，
  见第 5–7 行的注释）。同一二进制 + 同一种子集 + 同一 `-seed` → libFuzzer 的变异序列**确定**，
  5 个 rep 就是同一次运行的 5 次重放。
